# V1.0-E2 更新清单

- **替换预算修正**：`q_budget` 与 `q_joint` 不再扣除 `beta_budget * scarcity`；改为将冻结的 Q-gap 与多阶段预算条件下的未来期望成本差进行凸组合。
- **保留历史对照**：`q_budget_heuristic` 和 `q_joint_heuristic` 对应 V1.0-E1 旧评分，默认 legacy 系数 0.1。
- **分支正确性**：Keep 保留预算 b；Edit 消耗 1 个改约机会，后续每一阶段最多再消耗 1 次；每条模拟样本/候选分支独立推进物理运行状态。
- **风险采样稳定性**：独立参考 N=256、M=16/64/128、3 个重复批次。输出风险 MAE、候选排序稳定性、决策一致率、重复批次动作翻转率和运算时间。
- **MPC 采样敏感性**：单独比较 MPC-M=4/8/16，避免将 MPC 抽样噪声与 CVaR 抽样噪声混淆。
- **新增单元测试**：8 个纯模块测试已通过；真实 `IAMUEventEnv` 集成测试需要在服务器执行（交付环境没有原始 V0.9 引擎快照或 best.pt）。
- **实验命令**：见 `README_E2_多阶段预算前瞻与风险采样稳定性.md`。

此次不改变真实环境的奖励、DDQN 网络、岸电模型或 ERL-DDE 接口；不会声称多阶段贪心后续修复是严格最优的多阶段随机规划。
