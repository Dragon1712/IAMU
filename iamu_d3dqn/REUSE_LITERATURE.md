# Literature and code reuse audit (verified 2026-11-12)

Scope distinction: **published paper + public code confirmed**, **published paper but no verified code**, and **public demo not established as peer-reviewed code**. No external repository's code is copied into this package.

## Publication-linked repositories appropriate for reuse

1. **Li et al., ERL-DDE**, *Swarm and Evolutionary Computation* 100 (2026), 102241. Authors' repository: https://github.com/EvoNexusX/2024LiERLDDE . This is the **most direct reuse**, containing the actual C++ berth/quay-crane environment and frozen `ES` policy; the installed Linux port at https://github.com/Dragon1712/IAMU is used as the expected local source layout. This prototype replays an existing trained model as a scheduling-*hint* generator without retraining. **It does not implement future published commitments or shore power**; those are provided by new research code.

2. **Aslam, Michaelides & Herodotou (2024)**, “Optimizing Multi-Quay Combined Berth and Quay Crane Allocation Using Computational Intelligence,” *Journal of Marine Science and Engineering* 12(9), 1567; companion VEHITS '24 work. The authors' public repository https://github.com/cut-dicl/cibapqcap explicitly associates source code with their papers; it provides cuckoo search, genetic algorithm, particle swarm and MILP code, and random/real instances. **Reuse:** additional static berth/quay-crane baselines and input-conversion benchmarks. **Limit:** multi-quay static allocation, not our dynamic commitments or shore-power budgets. GitHub lists **Apache-2.0** (respect license and data terms).

3. **Santini (2026)**, “Solving Berth Allocation Problems via Selective Graph Colouring” and related published BAP formulations. Repository https://github.com/alberto-santini/berth-allocation-problems ; includes real-derived instances, best known solutions and a generator. The currently inspected `master` file tree does **not** expose the `models/bap` directory mentioned by some search snippets; do not assume those solver files are present. **Reuse:** independent dynamic-instance datasets, generators and best-known-solution comparisons; any solver implementation needs separate verification. **Limit:** not a ready-made ETA-announcement and cumulative revision-budget simulator. Parts of code are **GPL-3.0**; keep legal/licensing constraints in mind before copying it into another repository.

4. **Ernst, Oğuz, Singh & Taherkhani (2017)**, “Mathematical models for the berth allocation problem in dry bulk terminals,” *Journal of Scheduling* 20, 459–473. University OR library source: https://github.com/andreas-ernst/Mathprog-ORlib/blob/master/info/readmeBAP.md . The repository states that input instances and OPL `.mod` formulation source are provided. **Reuse:** mathematical model reference and benchmarking datasets, with format conversion. **Limit:** OPL and dry-bulk berth model, not ERL-DDE crane/time semantics or dynamics-with-revision budgets.

5. **Kim et al. (AAAI 2023)**, “Offline Pickup and Delivery Problem with Time Windows via Rolling Horizon Trip-Vehicle Assignment.” Source https://github.com/MAS-Research/RollingHorizon . Although about road vehicles, the repository explicitly ties to the paper and contains a runnable rolling-horizon C++ implementation. **Reuse:** concepts for incremental reoptimization, commitment invariants, event clocks and change-aware comparisons. **Limit:** fundamentally different domain, requires a MOSEK license according to README; cannot simply swap in for berth/shore-power control.

## Highly relevant published articles, but runnable author code not verified

- **Ji et al. (2022)**, “Hybrid rolling-horizon optimization for berth allocation and quay crane assignment with unscheduled vessels,” *Advanced Engineering Informatics* 54, 101733: https://doi.org/10.1016/j.aei.2022.101733 . Its event-driven + periodic horizon and urgency/margin concept are especially relevant to **when to replan**. The original article was verified; no associated public runnable repository was confirmed in this search.
- **Lv et al. (2024)**, “Dynamic berth allocation under uncertainties based on deep reinforcement learning towards resilient ports,” *Ocean & Coastal Management* 252, 107113: https://doi.org/10.1016/j.ocecoaman.2024.107113 . Dynamic ETA and service-time uncertainty, but no author code verified.
- **Wang et al. (2026)**, “An integrated robust framework for berth, yard, and shore power planning considering vessel arrival uncertainty,” *Ocean Engineering* 358, 125850: https://doi.org/10.1016/j.oceaneng.2026.125850 . Strongest relevant source for shore-power compatibility + uncertainty + advance commitments. No runnable author code verified.
- **Zhang et al. (2025)**, “Collaborative Optimization of Shore Power and Berth Allocation Based on Economic, Environmental, and Operational Efficiency,” *JMSE* 13(4), 776: https://doi.org/10.3390/jmse13040776 . NSGA-III shore-power multi-objective model; no public author source confirmed.
- **Wang et al. (2025)**, “Optimization of joint shore power and berth allocation under time-of-use electricity pricing,” *Journal of Dalian Maritime University* 51(2), 77–86: https://doi.org/10.16411/j.cnki.issn1006-7736.2025.02.009 . TOU energy and emissions models; no verified code repository.
- **Chen et al. (2026)**, “Neural network-enhanced branch-and-bound algorithm within an event-driven rolling-horizon framework for the berth allocation problem,” *Ocean Engineering* 364, 127072: https://doi.org/10.1016/j.oceaneng.2026.127072 . Event driven rolling horizon with neural branch-and-bound; no author code verified.

## Public repositories not to represent as official paper implementations

- https://github.com/Hisen717/berth-qc-joint-optimization-public is a clear, runnable berth/crane **course-design demonstration** with a Python baseline and GA, but its README does not establish it as an implementation of a peer-reviewed paper. Useful for prototyping only; do **not** cite it as author reproduction code.

## Reuse recommendation

**Now:** original ERL-DDE frozen model + local dynamic commitment layer, together with `cut-dicl`/Santini datasets as independent benchmarks. **Next:** port the event/periodic triggers inspired by Ji et al., and introduce shore-power constraints from Wang et al. **Only later:** train a new outer **revision-decision** policy while preserving frozen ERL-DDE weights. Distinguish a fresh algorithm implementation inspired by an article from directly reusing its public source code.
