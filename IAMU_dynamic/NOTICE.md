This package contains newly authored experimental code; it does NOT bundle
original ERL-DDE C++/Python sources, third-party datasets, or trained weights.
Optional `legacy_erldde.py` includes the user's locally available original
`BACAP_env.cpp` at compile time via an unmodified include statement and runs
the user's local original `model.py` under frozen inference.

Check the original repositories' licenses and cite the corresponding papers
before redistributing derivative artifacts. The example TSV here is synthetic.
